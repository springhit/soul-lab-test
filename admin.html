使用步骤
1. 点「下载 codes.js」
2. 把 codes.js 和 index.html 一起上传到你的 GitHub 仓库
3. 打开 GitHub Pages 设置，生成网址
4. 把「网址 + 验证码」发给对方
5. 对方答完 16 题，该码立即在本机失效

注：纯静态网页没有服务器，「是否已使用」记录在答题者自己的浏览器里。
同一台设备无法重复使用，换设备理论上可再用一次——如需绝对防重，请用 README 里的云端加固方案。
